# Linux and HPC Environment

## Objective

Set up a working Linux environment for computational physics and become comfortable working on an HPC workstation.

## Starting Point

Before this project, I had very limited experience with Linux and command-line tools.

## Skills Learned

- Linux filesystem navigation
- Shell commands
- Installing software
- Compiling scientific software
- Using GNU compilers
- Understanding MPI
- Working over SSH
- File permissions
- Environment variables

## Challenges

- Missing compilers
- Missing libraries
- Understanding build systems
- Learning terminal-based workflows

## Outcome

By the end of this stage I was comfortable working entirely from the Linux terminal and was ready to begin building FLASH.
